# Code and data provenance

This research builds on [MDGen](https://github.com/bjing2016/mdgen), by Bowen Jing, Hannes Stark, Tommi Jaakkola and Bonnie Berger. The research runtime imports MDGen geometry, residue constants, model and transport helpers. MDGen is not vendored or relicensed here. Its MIT license and any file-specific notices remain applicable when installing or redistributing it.

The tetrapeptide data source is https://huggingface.co/datasets/bjing-mit/tetrapeptide-sims. Dataset and checkpoint redistribution rights must be checked separately from code licenses. This repository contains result summaries, not the source dataset or trained weights.

The proposed Apache-2.0 license for original code is pending an ownership and per-file provenance review. No blanket license grant is asserted for third-party code, datasets, or checkpoints. Public source availability is not yet a completed open-source release.
