# 研究代码说明

本目录保留实际研究实现，便于检查“实验究竟如何做的”。它与 `src/molmotion` 的轻量公共接口用途不同。

| 目录 | 包含内容 | 仍需要的外部材料 |
|---|---|---|
| runtime | 原模型、单尺度 baseline、训练、评估及画图 | MDGen、预处理缓存、split、READY 标记、归一化参数 |
| repair-runtime | 慢分支 dropout、几何损失分支解耦等修复 | 同上及匹配的起始检查点 |
| audits | 固定预算、收敛、修复评估与梯度探针 | 成对检查点、验证集、原目录约定 |
| mdgen-baseline | 官方模型的项目训练评估适配 | MDGen、其依赖及实验输入配置 |
| applications | 8 分子 pilot、24 分子复核、等总耗时实验 | 已筛选／生成输入、PDB、OpenMM 及对应数据 |

新增文件出处与哈希见 `docs/added-source-manifest.json`。部分机器专用项目路径替换成了 `/path/to/...`；这不代表已完成跨机器适配。

训练运行前应配置 `MDGEN_REPO`、`V2_DATA`、`V2_ROOT`。原代码会将 MDGen 目录插入 `sys.path`，存在同名模块问题；审计代码对训练模块采用显式路径加载。不要简单把所有目录都加入 PYTHONPATH 后混用版本。

本次没有发布原服务器登录信息、调度提交脚本，也没有将大型权重或训练数据放入 Git。发布目标是可审查的研究代码与逐步完善的调用接口，不承诺现阶段一条命令重跑全部历史实验。
