# MolMotion 工具包可行性与发布路线

## 判断

可行。已有真实慢快模型、单尺度 baseline、评估代码和应用对照，可先发布研究复现版。当前最有辨识度的方向是“四肽轨迹候选生成—质量筛选—物理模拟—构象覆盖评估”。不能把它宣传为已全面超过 baseline 的通用分子模拟器。

## 当前发布内容

源码、原始训练与修复 runtime、可安装的模型/指标模块、历史证据及 2026-11-08 作图文件索引与数值长表。权重和源数据不放入 Git。已验证 wheel 构建、安装和三个模型/指标契约测试；未验证完整干净环境下的训练复现或公开权重推理。

## 接口建议

- generate：先支持经过校验的四肽输入，提供编码、归一化、采样、几何解码完整链路。
- evaluate：同时评价结构合理性和运动分布，明确单位、时间间隔、掩码及聚合方式。
- propose_seeds：提供候选构象、筛选记录和模拟输入，比较等仿真步数与等总耗时两种预算。
- export：确认原子拓扑、顺序、坐标单位、帧间隔后输出 PDB/XTC。

## 发布前必须补齐

1. 冻结适用模型权重、配置、特征版本、归一化参数、校验和及固定测试样例。
2. 完成推理入口与兼容性检查，不应直接运行未经信任的 pickle 权重。
3. 明确当前局限：键长有效率落后于单尺度 baseline；部分动态指标改善并不稳定；CPU 等总耗时实验没有端到端收益。
4. 复核逐文件来源和权利归属后决定原创代码许可证；保留 MDGen MIT 与其他第三方声明。数据、权重许可分别审核。
5. 完成环境锁定、端到端回归与小样例复现，再考虑 PyPI 和模型托管发布。

## 平台安排

GitHub 先承载代码、配置、证据与文档；通过测试后再准备 PyPI；许可核对后再托管权重。附件中的 slowfast-md 仍是建议名称，尚未核验或注册。当前项目使用 molmotion-research 的本地构建名称，未发布 PyPI。
REST/gRPC/MCP 不是第一阶段的依赖；Python API 和 CLI 先做扎实。

## 下一轮分析

先按分子、片段、噪声、预算和 checkpoint 匹配对照，再比较键长、速度 W1、ACF、碰撞率。区分 pooled 指标和逐分子配对差，报告置信区间。低学习率与慢分支修复做单独表，保留失败实验。最后分开讨论等仿真步数的探索覆盖收益与端到端耗时。
